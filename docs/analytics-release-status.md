# 1.12.0 自动匹配规则版本

日期：2026-10-20。本版默认不发送 schema_version，规则由支持自动匹配的统计服务端决定。先升级统计服务，再在游戏工程安装本版；旧统计服务可能拒绝无版本事件。显式数字 schemaVersion 保留在废弃兼容参数内，原样发送，但不限制新服务选版。

完整运行时与类型测试通过：时间戳与 OPPO 登录、19 项会话、41 项队列和恢复、16 项直传、21 项上下文及能力测试。支持默认无版本和旧第三参数两种调用。

本地 tgz 为 lgame-api-1.12.0.tgz，可通过 npm install 后接入。发布身份检查返回 ENEEDAUTH，当前尚未发布到 npm；包版本号不代表已经发布。未在真实小游戏项目或设备上验收，安装夹具和本机 HTTP 联调另行记录。源码随后按用户要求在 main 归档，尚未推送。

初始化一次 onAnalyticsResult 即可观察自动上报的逐条拒绝和批次错误，包含错误码、字段、message 和待发送数量，接入示例见[自定义打点](analytics.md)。

# 1.11.0源码交接与发布状态

日期：2026-10-20。当前修改保留在独立SDK checkout，尚未提交、推送或执行npm publish。本地安装包为 `lgame-api-1.11.0.tgz`，不会加入Git。

## 本版内容

- 初始化可显式提供 `app_version`、`os_name`、`device_model`，SDK逐条快照自动上下文、版本、北京时间与操作会话字段，不探测设备。
- 公开能力GET探测成功才向独立采集端发送扩展字段；旧采集端及原游戏转发路径继续使用五字段事件。
- 登录前后保持操作会话；同来源重复初始化保留操作会话，但继续清理登录及队列。同账户刷新与首次补UID兼容，换号或来源切换隔离。
- 首次提交冻结每事件协议与载荷，超时、能力变化和401重试不改同一事件，能力迟到响应受会话代次与总截止约束。
- UTF8批次和队列限制包含自动context与会话字段。

公开初始化示例、能力协议及兼容行为见[自定义打点](analytics.md)。全部示例使用占位域名和公开字段；公开包不包含服务端实现、数据库脚本、环境变量或凭据。

## 验证和使用

验证范围为 `npm test`（TypeScript构建、时间戳与平台登录、19项会话、41项队列/恢复、16项直传、21项自动上下文与能力协商、公开类型检查）、`npm run build`、`npm pack --dry-run` 与本地 `npm pack`。本地包入口是dist/index.js及dist/index.d.ts；Git不收录dist、node_modules或tgz。

README的npm安装命令获取已发布版本，源码版本不代表npm已经发布。验证本版可使用本地tgz安装并锁定依赖；各平台实际设备、断网恢复、后台切回及生产容量需在游戏项目继续验收。
